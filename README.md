# Master Thesis - LiDAR-Visual Mapping

Maps of the environment are essential for autonomous car navigation. Metric maps should be ideally both - geometrically accurate and photorealistic. To achieve this we combine LiDAR and camera data and utilize radiance and signed distance fields to represent the environment while handling dynamic objects: image-based detection via Grounded SAM 2 and LiDAR-based removal via PCA. The result is static-world reconstruction even in dynamic scenes.
